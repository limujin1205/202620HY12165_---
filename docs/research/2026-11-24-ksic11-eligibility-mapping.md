# 지식산업센터 입주대상 업종 — 산업집적법 시행령 × KSIC 제11차 매핑

- 분류 기준: 한국표준산업분류 제11차(KSIC-11, 2024.7.1. 시행)
- 법령 기준: 사용자 제공 「산업집적활성화 및 공장설립에 관한 법률 시행령」(2026.9.18. 표기본), 제6조제2항·제3항 및 제36조의4
- 데이터 성격: **법령의 업종명과 KSIC 분류의 대응표**. 개별 사업체 또는 개별 지식산업센터에 대한 입주 허가·승인 목록이 아님
- 코드 표기: 숫자 2~5자리. **접두 코드**(예: `62`)는 해당 하위 KSIC 업종군을 뜻하며, `*`는 분류 범위 일부만 법령에 부합할 수 있음을 뜻함
- 주의: 「산업발전법 시행령」의 지식서비스산업 목록은 이 법 시행령 제6조의 지식산업 목록과 **동일하지 않음**. 아래 매핑은 시행령 제6조를 우선함

## 4. 데이터 정규화 규칙

| 필드 | 값·규칙 |
|---|---|
| `ksic_revision` | `11` |
| `ksic_code` | 문자형. 2~5자리 숫자, 앞자리 0 보존 |
| `code_match_type` | `PREFIX`(상위 분류의 하위업종 포함) / `EXACT`(해당 세세분류) / `ACTIVITY_REVIEW`(실제 사업 확인) / `NO_FIXED_CODE` |
| `legal_category` | `KNOWLEDGE` / `ICT` / `MANUFACTURING` / `VENTURE` / `SUPPORT` / `OTHER_RECOGNIZED` |
| `legal_basis` | 시행령 제6조제2항 각 호, 제6조제3항 각 호, 제36조의4 등 정확한 조·항·호 |
| `legal_condition` | 업종 이외의 기관 자격, 사업내용, 관리기관 인정, 면적 제한 등 |
| `mapping_status` | `DIRECT_GROUP` / `DIRECT_EXACT` / `CONDITIONAL` / `NEEDS_KSIC_VERIFICATION` |
| `eligibility_result` | 코드 매핑 결과와 별도 관리. `MATCHED_CATEGORY`는 **입주 허가**를 의미하지 않음 |

### 분류 시 주의사항

1. KSIC는 통계상 산업분류이며, **국세청 업종코드와 다르다**. 국세청 코드만 입력된 경우 별도 연계표가 필요하다.
2. 시행령 제6조제2항과 제3항의 업종이 **서로 중복**될 수 있다. 중복은 오류가 아니며 근거 조문을 각각 보존한다.
3. 상위 분류 코드의 매핑은 그 아래 **모든 세세분류가 조건 없이 적합하다는 뜻이 아니다**. 조건부 행은 실제 사업내용을 확인한다.
4. 산업단지 안의 지식산업센터는 해당 산업단지 **관리기본계획상 유치업종·제한업종**과 입주자격을 별도 적용한다(시행령 제6조제1항, 법 제33조).
5. 지원시설은 별도 유형으로 판단한다. 시행령 제36조의4제3항은 동일 세세분류 업종 지원시설의 총 건축연면적에 대한 제한을 둔다.
