   - 법적 우선순위 규정을 학습하여 낙찰가 및 근저당·일반 채권자 정보 입력 시 배당표 자동 산출

   - 보유 담보 부동산 위치 기반으로 재개발, 교통 호재 등 주변 개발 소식 기사를 지도에 시각화
