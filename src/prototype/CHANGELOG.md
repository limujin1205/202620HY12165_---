# 📝 지산입주 도우미 업데이트 내역

## v0.6 — 2026-11-24
업종코드(KSIC) 기반 판정으로 전환하고 최신 법령을 반영했어요.

### 1. 업종코드 검색 (신규)
- 한국표준산업분류 **제11차** 1,205개 코드를 페이지에 내장 (`docs/research/2026-11-24-ksic11-lookup.json` 기반)
- 업종명(예: `응용 소프트웨어`)이나 코드(예: `58222`)로 검색
- 사업자등록증에 적힌 **제10차 코드**를 넣으면 바뀐 11차 코드로 자동 변환 (코드가 바뀐 125개 대응)
- 최대 3개 선택, 첫 번째를 주업종으로 판정
- 사업 설명을 쓰면 후보 코드를 제안 (판정에는 쓰지 않음)

### 2. 규칙 판별 정확도 개선
- 키워드 판정 → **업종코드 × 시행령 매핑표** 판정 (`2026-11-24-ksic11-eligibility-mapping.md` 기준)
  - 지식산업(영 제6조제2항) 29개 호, 정보통신산업(제3항) 6개 호, 제조업(KSIC 10~34)
  - 매핑 수준을 `입주 가능 범주` / `조건부 가능` / `관할 기관 인정 필요` / `판단 보류` / `입주 어려움`으로 구분
- 코드를 고르지 않으면 단어만으로 판정하지 않고 **판단 보류**로 표시
- 서울디지털국가산단: 관리기본계획의 입주대상(금융투자업, 부동산 임대·공급업, 수직농장 등)과 입주제한업종(용수다소비, 입주부적격)을 코드로 판정
- 지원시설 제외(영 제36조의4제2항): 농림어업·광업·제조업(근생 입주 가능 제조업은 예외)·숙박(관광호텔 예외)을 코드로 판정
- AI는 규칙 판정을 뒤집지 않고, **사업 내용과 코드가 맞는지**와 놓친 조건만 보완

### 3. 법령 최신화 (시행령 2026.9.18. 시행본)
- 영 제6조제2항 **제15호 삭제**(2026.4.28.) 반영, 제26호(이러닝업)·제29호(관리기관 인정 산업) 추가
- 제3항 정보통신산업에 뉴스 제공업, 영상·오디오물 제공 서비스업 반영
- 건축물대장 '공장' 표기만으로 입주를 확정하지 않고, 공장이 아닌 호실을 일률적으로 지원시설로 보지 않도록 수정
- 배출 공정 체크만으로 입주 금지를 확정하지 않음 (환경 인허가 확인으로 안내)
- 산단 안: 입주계약 신청서(시행규칙 별지 제25호) + 사업계획서(별지 제2호의2·제2호의3) 안내, 지원시설 입주계약 예외(영 제48조의2제3항) 안내
- 산단 밖: "입주 신고서" → **"입주 사업계획서"**로 변경 (통일된 법정 서식이 없음)
- '계획입지' 표기만으로 산업단지 명칭·관리기관을 확정하지 않도록 표시 변경
