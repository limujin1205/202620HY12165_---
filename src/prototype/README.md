# 🏢 지산입주 도우미 (프로토타입)

지식산업센터 호실을 **분양받은 기업**이 입주 자격을 확인하고 입주 서류 초안을 만드는 웹페이지예요.
`index.html` 파일 하나로 동작해요. 브라우저로 바로 열면 돼요.

## 흐름
1. **취득 방식**: 분양 (임대차·매매·경매낙찰은 준비 중)
2. **센터 선택**: 서울 지식산업센터 381곳 검색, 산업단지 안/밖 구분, 건축물대장 호실 용도 확인
3. **자격 판별**: 산업집적법 제28조의5·시행령 제6조·제36조의4와 서울디지털국가산단 관리기본계획 기준
4. **서류 작성**: 산단 안이면 입주계약 신청서, 밖이면 입주 신고서 초안 (DOCX 다운로드)
5. **감면·지원**: 최초 분양 취득세·재산세 감면 안내, 지원사업 추천 (예시 데이터)

## 데이터 출처
- 서울특별시 지식산업센터 현황 (2026.02. 기준) — 산단구분 '계획'=산업단지 안, '개별'=산업단지 밖으로 처리
- 한국수출(서울디지털) 국가산업단지 관리기본계획 (산업통상부고시 제2026-042호, 2026.5.15.)
- 산업집적법 및 같은 법 시행령, 구리시·금천구청 안내 페이지
